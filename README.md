## 📖 About the Project

**WiFi Profile Viewer** is a Python-based utility designed to explore Wi-Fi network profiles saved on your own computer.

The project demonstrates how Python can interact with operating-system networking features to identify previously saved Wi-Fi profiles and present available network information in a simple and organized way.

It is primarily an **educational networking project** for understanding Python system interaction, command execution, network profiles, and basic cybersecurity concepts.

```text
💻 Computer
    ↓
📡 Saved Wi-Fi Profiles
    ↓
🐍 Python
    ↓
🔍 Profile Detection
    ↓
📋 Organized Information
```

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/WiFi-Profile-Viewer.git
```

```bash
cd WiFi-Profile-Viewer
```

### 2. Make sure Python is installed

Check your Python version:

```bash
python --version
```

---

## ▶️ Usage

Run the Python program:

```bash
python wifi_viewer.py
```

The program will scan the Wi-Fi profiles available to the current user/system and display the information it is permitted to access.

> ⚠️ The exact information available depends on the operating system, user permissions, and saved network configuration.
